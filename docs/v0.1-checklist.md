## H. 明确的技术债（写出来，不是藏起来）

| 债务 | 影响 | 计划 |
|---|---|---|
| `outbox` 只增不删 | 长期运行会膨胀 | v0.2：保留策略 + 定期清理（`operations.md` §5 已给 SQL） |
| 无背压 / 无队列长度上限 | 突发流量可能打爆 worker | v0.3 |
| 无租户公平调度 | 大租户可饿死小租户 | v0.3 |
| 顺序投递未实现 | 消费者需自行处理乱序 | 明确列为「不保证」 |
| 固定窗口限流 | 窗口边界可 2 倍突刺 | v0.3 换令牌桶 |
| 无 SDK | 接入需手写 HTTP | v0.4（可选） |
| `endpoint.url` 未做 SSRF 防护（内网地址可填） | 多租户场景是真实风险 | v0.2：出网 IP 白名单 / 内网地址拒绝 |
| 无 outbox 归档、无 attempt 归档 | 磁盘增长 | v0.2 |
